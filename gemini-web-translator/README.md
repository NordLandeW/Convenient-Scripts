# Webpage Translator

使用 Gemini、OpenRouter 或 OpenAI / 兼容 API 翻译网页的 Tampermonkey 脚本。支持 Chat Completions / Responses、流式回填、并发批次、原文还原和经过原文校验的本地缓存。

## 安装与配置

1. 将 `gemini-web-translator.js` 安装到 Tampermonkey。
2. 从 Tampermonkey 菜单选择对应平台的“密钥”，在浏览器原生对话框中输入 API Key。取消保持原值；留空后确认可删除该平台密钥。
3. 使用 OpenAI 兼容服务时，从菜单“OpenAI / 兼容 API 地址”设置 Base URL，并核对确认框中的完整目的地址。可输入根地址、API 前缀或以 `/chat/completions`、`/responses` 结尾的地址，例如 `https://gateway.example/v1`。密钥和网页内容将发送到这个服务；HTTP 地址不提供传输加密。
4. 按 **Alt+S** 或选择菜单“设置”，选择平台、模型、目标语言和其它参数。手动填写的模型代码优先于下拉列表；推理强度默认不指定，沿用服务端行为。

脚本请求 `@sandbox DOM`，敏感操作检查实际 `GM_info.sandboxMode`，接受 `dom` 和 `js`。若脚本管理器报告 `raw` 或未知模式，脚本会提示并停止密钥管理和翻译；需要使用支持隔离沙箱的 Tampermonkey 环境。其它脚本管理器的兼容性取决于这些 API 和隔离语义的实现。

已有平台密钥继续使用原来的 GM 存储键。网页设置面板仅显示是否已配置，不读取密钥到输入框，也不能修改 API 地址。浏览器原生对话框由油猴菜单打开；不要把密钥填入网页仿制的表单。一般设置仍位于网页共享 DOM，并不是隔离的扩展设置页。

## 翻译与恢复

- **Alt+T / 菜单“翻译网页”**：未翻译时开始；正在翻译时取消并安全还原；已有译文时还原。
- **菜单“重试未完成的翻译”**：保留已完成部分的结果，重新提取当前页面，只发送尚未命中的内容。关闭本地缓存时，当前页面会话内仍保留重试所需的成功结果；刷新后这些内存结果消失。
- 写回前检查文本节点仍连接到页面且内容与请求时的原文一致。还原只处理仍保留脚本所写译文的节点，网站随后更新的内容会保留。
- 跳过代码、编辑区域、不可翻译标记和实际不可见的文本。动态新增内容需要再次触发翻译；脚本不自动持续监视网页。

每个文本节点是一条翻译记录，保留原有元素和事件绑定。专名保留原文，缺少通行译名的专业术语保留原文。

## 缓存与批次

缓存按照原文、父元素文本上下文、目标语言和翻译配置核验；模型、API 地址/协议、推理强度或提示词变化会进入不同的缓存配置。URL 保留查询参数、片段和尾部斜杠，URL 相似度仅用于寻找同源候选页面。节点位置变化不会把另一段译文套到新文本上；部分命中时只请求缺失部分。

- 本地缓存默认启用，默认上限 **10 MB**、有效期 **7 天**；可在设置中修改，`永不过期` 关闭时间过期。
- 默认候选 URL 相似度 **95%**。清除当前页缓存会清理当前语言下可能参与复用的候选页面，包括其它模型的记录；“清除全部”清空本脚本的翻译缓存。
- 旧版仅按节点位置保存的缓存缺少原文证据，升级后自动失效并回收；平台和语言设置保留。
- 成功批次独立保留。单页结果超过缓存上限时不写入本地缓存，保留其它页面缓存；若本轮未完成，成功部分仍可在当前会话中复用。
- 默认每批 **500 个节点**、并发 **8 个请求**。按节点数量分批，并发数控制同时活动的请求数量。

模型输出必须是属于本批、顺序有效的 CSV 记录及结束标记。无效格式、重复/越界 ID、结束标记后的记录和不完整响应会报告失败；它们不会被算成“不需要翻译”。合法省略的记录仍按原有约定视作无需修改。

HTTP 鉴权/参数等永久错误停止本轮请求；网络故障、408/409/429 和服务端错误进行最多两次自动重试，采用退避和抖动并尊重 `Retry-After`。收到限流后的新请求共享冷却期。取消会立即结束本地等待、取消活动请求，迟到回调不会修改重试或新一轮翻译；远端服务是否已完成或计入请求由服务端决定。

## 开发验证

在仓库根目录执行，无需安装 Node 单元测试框架：

```sh
node --check gemini-web-translator/gemini-web-translator.js
node --test gemini-web-translator/tests/*.test.cjs
```

测试使用真实源码函数、隔离 GM 存储和假 API，不读取真实密钥或向翻译服务发送请求。

另有可选的离线浏览器集成测试。需要已安装的 Playwright 及 Chromium 浏览器；`PLAYWRIGHT_MODULE` 可以指定现有 `playwright` / `playwright-core` 包路径，`BROWSER_CHANNEL` 可以选择已安装的 Chromium 浏览器通道：

```sh
node gemini-web-translator/tests/browser.cjs
```

该测试新建 headless 浏览器配置，通过 CDP 隔离世界验证共享 DOM、原生对话框、内容提取及部分失败恢复。所有页面请求均由本地 fixture 响应，GM API 使用测试实现。它不启动用户的浏览器配置，也不能代替实际 Tampermonkey 安装后的兼容性验收。
