# Background-image-filter

以启发式评分在指定文件夹中选出最适合当成壁纸的图片。

## 运行

```bash
python bg-filter.py --folder "D:\Pictures" --page-size 12 --ratio 16:9
```

- `--folder` 要扫描的文件夹（可稍后在界面里选择）
- `--page-size` 每页缩略图数量，默认 12
- `--ratio` 目标纵横比，例如 `16:9`；默认取屏幕比例

## Qt 版本

`bg-filter.py` 是 PySide6 (Qt 6) 实现。旧的 Tk 实现 `bg-filter-tk.py` 保留原有评分，可用于对照。界面使用 Qt 原生的 Windows 11 (WinUI) 控件样式，中文优先 Microsoft YaHei UI、英文回退 Segoe UI；其他平台自动回退到 Fusion。

渲染路径：

- 缩略图网格和预览画布在可用时使用 `QOpenGLWidget`，由 GPU 完成合成与交互缩放的临时插值。
- 最终高质量缩放仍由 Pillow 的 LANCZOS 在后台线程完成；GPU 不参与图像重采样。
- 设置 `BG_FILTER_RENDER=raster` 可强制软件光栅渲染；没有可用 OpenGL 上下文时会自动回退。

## 操作

- 单击缩略图打开预览；右键在外部程序中打开并复制文件。
- `←` / `→` 翻页或切换图片；预览中滚轮缩放、拖动平移。
- “比例遮挡” 按目标纵横比压暗缩略图和预览中不可见的部分。
- “跳至” 支持页码钳制；`重新计算` 会按当前比例重新扫描、评分和排序。

## 评分规则（Qt 版本）

总分为比例分、有效分辨率分、色彩分与 GIF 惩罚之和，按降序排列。PNG、JPEG 等静态格式使用相同评分；文件体积仅显示，不参与排序。

- **比例分**：保持原规则，`200 × 居中铺满目标比例时保留的面积比例`。
- **有效分辨率分**：以居中裁切后剩余像素面积与目标像素数之比 `p` 计算 `-40 + 85 × (1 - exp(-2p))`。分值平滑递增，趋近 45；刚好达到目标像素数时约为 33.5，继续增加分辨率的收益逐渐降低。
- **色彩分**：在同一可见区域计算 Hasler–Süsstrunk colorfulness `C`，映射为 `40 × C / (C + 45)`。灰度图为 0，色彩分上限为 40。这是偏好彩色画面的启发式，纯色高饱和画面也可能加分，不等同于配色种类或审美质量。
- **GIF 惩罚**：保留原有 −1000 分，包括静态 GIF。

目标像素数默认取启动时主屏的物理像素总数（包含系统缩放系数）；无法取得屏幕时使用 1920×1080。修改目标比例保持这个像素总数，按新比例计算等面积目标尺寸。状态栏显示此次评分的目标尺寸。比例遮挡的勾选只影响显示，评分始终按居中裁切计算；预览中的额外缩放、拖动不改变评分。

色彩统计使用 8 位 RGB 的有符号对立色通道：`rg = R - G`、`yb = (R + G) / 2 - B`，`C = sqrt(var(rg) + var(yb)) + 0.3 × sqrt(mean(rg)² + mean(yb)²)`。分析图长边不超过 256 像素，透明区域先合成到中性灰色；完全透明像素的隐藏 RGB 不贡献色彩。该低分辨率统计是近似值，不改变展示图片的高质量重采样。权重与尺度是固定初始值，没有按当前目录归一化。

预览底部显示总分及各分项。扫描、解码和评分在后台执行。左下角先显示已找到的图片数，再显示已分析数/总数；有新进度时约每 100 毫秒更新，第一张和分析完成时立即报告。最终状态包含失败数量；损坏或无法读取的图片记为 −10000 分。切换文件夹、重新计算或关闭窗口会取消旧批次的排队任务，已经开始的最多 4 路分析完成后退出，旧批次结果不会覆盖新结果。

进程内保留最多 64 MiB 的分析图像素缓存，按路径、文件大小及时间戳识别变化；重新计算会重新扫描并检查文件。切换比例复用仍驻留的分析图，被淘汰的图片需要重新解码。缓存不落盘，原图解码及展示用缓存的额外内存不计入此上限。打开的预览保留其打开时的排序、比例及评分快照，重新打开可查看新评分。

指标来源：[Measuring colorfulness in natural images](https://doi.org/10.1117/12.477378)。

## 测试

安装依赖后，在本目录运行：

```bash
python -m unittest discover -s tests -v
```

测试使用合成图片与 Qt offscreen 平台，不弹出可见窗口。

pip install -r requirements.txt
